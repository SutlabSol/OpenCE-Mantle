## 2. Quick Matrix: How Every Tag Creation Workflow Works & How Mantle Simplifies It

| What You Want to Build | Traditional HEK / Legacy Tool Workflow (8–15 Manual Steps) | OpenCE Mantle 1-Stop Workflow (Built & Planned) |
| :--- | :--- | :--- |
| **Custom 3D Scenery, Vehicle, Weapon, or Equipment from `.obj`** | Export `.jms` from Blender $\rightarrow$ `tool bitmaps` $\rightarrow$ create `.shader_model` in Guerilla $\rightarrow$ `tool model` $\rightarrow$ export collision `.jms` $\rightarrow$ `tool collision-geometry` $\rightarrow$ create `.scenery` tag $\rightarrow$ place in Sapien $\rightarrow$ `tool build-cache-file`. | ✅ **Built (`Tools -> Build Custom 3D Object Tag (.obj)...`)**: Pick `.obj` + `.png` (with built-in UV unwrapper & wireframe template exporter) $\rightarrow$ Mantle compiles `bitm`, `soso`, `mod2`, `coll`, and root object tag and injects directly into the map! |
| **Vehicle Physics (`phys`) & Suspension** | Create triangle-free `.jms` with `#` marker spheres $\rightarrow$ `tool physics` $\rightarrow$ guess friction scales, `relative_mass`, and `powered_mass_points` in Guerilla $\rightarrow$ re-export `.jms` to tweak wheel positions. | **3D Viewport Physics Sphere Editor (Vol. 02)**: Toggle the **Physics (`phys`) Layer** on any vehicle in the 3D Viewport $\rightarrow$ drag/scale `#` mass-point spheres and friction arrows directly on the 3D model $\rightarrow$ Mantle recalculates `center_of_mass` and the 3×3 `inertial_matrix_and_inverse` automatically on save! |
| **Interactive Doors, Elevators & Switches (`mach` + `ctrl`)** | Rig bones in Blender $\rightarrow$ parent collision hull to moving bones $\rightarrow$ export `device position.JMO` $\rightarrow$ `tool animations` $\rightarrow$ create `mach` & `ctrl` tags $\rightarrow$ create `device_group` in Sapien $\rightarrow$ link `position_group` indices manually. | **Interactive 3D Door & Switch Builder (Vol. 02)**: Select any mesh/door $\rightarrow$ set Closed (`0.0`) and Open (`1.0`) poses with the 3D gizmo $\rightarrow$ Mantle generates the rigged `mod2`, `coll`, and `antr` (`device position` track), computes `inv_position_transition_time` & `door_open_time_ticks`, and lets you draw a visual link line from any `ctrl` switch to any `mach` door! |
| **Effects (`effe`), Particles (`part`, `pctl`), Lights (`ligh`) & Glow (`glw!`)** | Manually wire `locations` markers, `events`, `parts` (remembering `type_class` FourCC), `particles` (`make_it_actually_work = 1`, `contact_deterioration = 0`), `ligh` (`specular_radius_multiplier = 2.0`), and `glw!` 5-marker splines across 6+ separate Guerilla windows. | **Visual Effect Timeline & Light/Glow Inspector (Vol. 03)**: Edit `effe` events, particle emitters, dynamic lights, and lens flares on a visual timeline with automatic `postprocess_proc` derived field calculation (`type_class`, `relative_direction_vector`, `cos/sin` frustum angles, `specular_radius_multiplier = 2.0`, and `glw!` crash validation). |
| **Dynamic Glowing Shaders & 3D Weapon Meters (`A in..D out`)** | Jump between `weap` (`A in = heat`), `object.functions` (`WaveFunction`), and `soso`/`smet` (`A out`) across multiple tag windows without visual feedback. | **Visual Function Node Graph & Curve Previewer (Vol. 03)**: Connect telemetry inputs (`heat`, `ammo`, `rpm`, `power`) $\rightarrow$ `CurveGraphVisualizer` $\rightarrow$ Shader/Light consumers in one unified view with live `0.0..1.0` slider scrubbing. |
| **Custom `ui.map` Main Menu & 3D Cutscene / NPC Choreography** | Edit `DeLa` `640×480` pixel coordinates blindly in Guerilla $\rightarrow$ swap BSP $\rightarrow$ place camera points in Sapien $\rightarrow$ hand-write `command_lists` and `.hsc` camera scripts $\rightarrow$ rebuild `ui.map`. | **Composite 2D `DeLa` + 3D Viewport `ui.map` Studio (Vol. 04)**: Drag 2D `DeLa` menu buttons directly over the live 3D Viewport, press <kbd>K</kbd> while flying in the 3D Viewport to drop keyframed `cutscene_camera_points`, click on the 3D terrain to lay down NPC `command_list` patrol/vehicle/animation paths, and link menu button focus events to 3D camera cuts in 1 click! |
